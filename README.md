# وصلة - المساعد الإداري الذكي

نسخة تجريبية ثابتة تعمل على GitHub Pages بدون خادم.

## تسجيل الدخول التجريبي
- اسم المستخدم: `admin`
- كلمة المرور: `1234`

## المزايا
- لوحة تحكم.
- بيانات الكادر مع الاستيراد من CSV/Excel والحفظ محليًا.
- بيانات أولياء الأمور مع الاستيراد والحفظ محليًا.
- الطلبات والمراسلات.
- روابط نظام نور، منصة مدرستي، ومنصة العمل التطوعي.
- تصدير نسخة احتياطية JSON.

## تنبيه مهم
هذه النسخة تستخدم `localStorage` داخل المتصفح ولا تحتوي على نظام دخول آمن أو قاعدة بيانات خلفية. لا تُستخدم لتخزين بيانات مدرسية حقيقية أو حساسة على مستودع عام. للإنتاج يلزم خادم/قاعدة بيانات آمنة وصلاحيات مستخدمين مناسبة.

## نشرها على GitHub Pages
ارفع الملفات الأربعة إلى جذر المستودع: `index.html`, `styles.css`, `app.js`, `README.md`، ثم من Settings > Pages اختر Deploy from a branch ثم `main` و `/root`.
